Question:
What does the letter "T" stand for in "GPT", the revolutionary architecture powering models like ChatGPT?

Options:
  A) Tensor
  B) Transformer
  C) Transfer
  D) Tokenizer

Correct Answer: B) Transformer
Explanation:
GPT stands for "Generative Pre-trained Transformer". The Transformer architecture was introduced by Google researchers in the landmark 2017 paper "Attention Is All You Need" and is the backbone of modern Generative AI.

QUESTION 2 [Topic: Latest AI Trends (RAG) | Level: Easy-Medium | Time: 20s]
----------------------------------------------------------------------------------------
Question:
What does RAG stand for in modern generative AI systems, used to ground LLM answers in external private documents?

Options:
  A) Recursive Automated Generation
  B) Real-time Augmented Gradient
  C) Retrieval-Augmented Generation
  D) Relational Analytical Graph

Correct Answer: C) Retrieval-Augmented Generation
Explanation:
Retrieval-Augmented Generation (RAG) fetches relevant external documents from a vector database or search index and passes them as context into the LLM prompt, drastically reducing hallucinations.

QUESTION 3 [Topic: AI Reliability & Safety | Level: Easy | Time: 20s]
----------------------------------------------------------------------------------------
Question:
In the context of Large Language Models, what is an AI "hallucination"?

Options:
  A) The AI produces fluent, confident statements that are factually false or completely fabricated
  B) The AI server runs out of GPU memory and abruptly restarts
  C) The AI translates text into an ancient forgotten language
  D) The AI deliberately pauses to simulate human thinking

Correct Answer: A) The AI produces fluent, confident statements that are factually false or completely fabricated
Explanation:
Hallucination occurs when an LLM generates syntactically convincing, confident statements that contain false assertions, invented citations, or incorrect data.

QUESTION 4 [Topic: Machine Learning Fundamentals | Level: Easy | Time: 20s]
----------------------------------------------------------------------------------------
Question:
A machine learning model achieves 99.8% accuracy on training data but performs terribly on unseen test data. What problem has occurred?

Options:
  A) Underfitting
  B) Overfitting
  C) Gradient Explosion
  D) Data Imbalance

Correct Answer: B) Overfitting
Explanation:
Overfitting happens when a model memorizes the noise, outliers, and peculiarities of the training dataset instead of discovering the underlying generalized pattern.

Recent frontier reasoning models (such as OpenAI o1/o3 and DeepSeek R1) excel at complex logic, math, and code primarily through which technique?

  B) Using "Test-Time Compute" and internal Chain-of-Thought reasoning before responding

QUESTION 6 [Topic: Data Science & Vector Search | Level: Medium | Time: 20s]
----------------------------------------------------------------------------------------
Question:
Why do modern AI search systems and vector databases (like Pinecone, Milvus, and Chroma) convert text and media into Vector Embeddings?

Options:
  A) To compress media files into smaller ZIP archives
  B) To convert data into high-dimensional numerical coordinates for semantic similarity search
  C) To scramble passwords for biometric encryption
  D) To automatically fix syntax errors in SQL queries

Correct Answer: B) To convert data into high-dimensional numerical coordinates for semantic similarity search
Explanation:
Vector embeddings represent semantic meaning as dense vectors in high-dimensional space. Closeness in vector space (e.g. cosine similarity) corresponds directly to conceptual similarity.

Question:
What does RLHF stand for, the critical alignment technique used to make raw pre-trained LLMs safe, helpful, and conversational?

Options:
  A) Reinforcement Learning from Human Feedback
  B) Recursive Language Hyperparameter Fitting
  C) Real-time Learning with Hardware Frameworks
  D) Random Linear Heuristic Filtering

QUESTION 13 [Topic: Generative AI & Computer Vision | Level: Easy-Medium | Time: 20s]

Question:
Which modern generative architecture powers high-quality image generators like Midjourney, Stable Diffusion, and Flux?

Options:
  A) Diffusion Models
  B) K-Nearest Neighbors (KNN)
  C) Decision Trees
  D) Support Vector Machines (SVM)

Correct Answer: A) Diffusion Models
Explanation:
Diffusion models learn to reconstruct high-fidelity images by iteratively reversing a process that adds random Gaussian noise to images, steered by text conditioning prompts.

QUESTION 14 [Topic: Machine Learning Evaluation | Level: Medium | Time: 20s]
----------------------------------------------------------------------------------------
Question:
When evaluating a machine learning model on highly imbalanced data (e.g., detecting rare credit card fraud where 99.9% of transactions are legitimate), which metric is LEAST reliable by itself?

Options:
  A) Precision
  B) Recall
  C) F1-Score
  D) Raw Accuracy

Correct Answer: D) Raw Accuracy
Explanation:
A dummy classifier that predicts "Not Fraud" for every single transaction will achieve 99.9% raw accuracy while detecting zero fraud cases. Precision, Recall, and F1-Score provide true diagnostic value.

QUESTION 15 [Topic: Modern Prompt Engineering | Level: Easy-Medium | Time: 20s]
----------------------------------------------------------------------------------------
Question:
What prompt engineering technique involves providing 2 to 3 example question-answer pairs directly in the prompt before asking the model to solve a new problem?

Options:
  A) Zero-Shot Prompting
  B) Few-Shot Prompting
  C) Model Quantization
  D) Gradient Descent

Correct Answer: B) Few-Shot Prompting
Explanation:
Few-shot prompting conditions the model on the target format and problem pattern by showing in-context demonstrations (shots) inside the prompt, without altering any underlying model weights.
